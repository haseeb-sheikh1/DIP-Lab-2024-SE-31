# Lab Task 01: Python Setup, Fundamentals, and Imports 🐍

##  Objective
The primary goal of this lab task is to configure the Python development environment (Python 3.14+ and VS Code), understand fundamental Python programming concepts, and install essential digital image processing packages (`numpy`, `pillow`, `matplotlib`).

##  Files Included
* `hello.py`: A simple verification script to test the Python environment setup.
* `basics.py`: Contains comprehensive exercises covering variables, data types, conditional statements, loops (for/while), functions, and Python collections (Lists, Tuples, Dictionaries, Sets).
* `lab01_imports.py`: Verifies the successful installation and loading of the required external image processing libraries.
* `2024-SE-31.pdf/docx`: The official, documented lab report with screenshots and explanations.
